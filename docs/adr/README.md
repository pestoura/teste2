# Architecture Decision Records

Record material decisions as small immutable ADRs.

Suggested naming:

```text
ADR-0001-short-decision-title.md
ADR-0002-next-decision.md
```

Each ADR should capture at least:

- status;
- context/problem;
- decision;
- consequences/trade-offs;
- security/operational impact where applicable;
- superseded/superseding ADR references.

Prefer a new superseding ADR over silently rewriting historical decisions.
