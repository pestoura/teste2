# Project Documentation

Keep project-specific documentation here. The central engineering standard, reusable capabilities and common CI implementation live in `pestoura/jarvas-engineering-platform` and should be referenced rather than copied.

Recommended project-local areas:

- `architecture/` — current architecture, boundaries and runtime/deployment model;
- `adr/` — material Architecture Decision Records;
- product/domain runbooks, acceptance evidence indexes and operational documentation as they become applicable.
